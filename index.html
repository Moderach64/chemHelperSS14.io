Журнал изменений

текущая версия 2.0
2.02026-11-20Выход на GitHub

Добавлено

  • Окно «Журнал изменений»: кнопка в панели над категориями и номер версии в подвале. Версии раскрываются по клику, свежая открыта по умолчанию. Закрыть окно можно кнопкой ✕, клавишей Esc или кликом по фону.
  • Кнопка «Развернуть все / Свернуть все» внутри журнала.
  • Номер версии v2.0 в подвале страницы.

Изменено

  • Проект собран для публикации на GitHub Pages: в одной папке лежат index.html, style.css, script.js и CHANGELOG.md, все ссылки относительные.
  • История пересобрана по версиям 1.0–2.0. CHANGELOG.md и окно на сайте показывают одно и то же.
1.32026-11-20Два оформления

Добавлено

  • Переключатель «Оформление: Стандартное / Экспериментальное» в панели над категориями. В экспериментальном оформлении каждый рецепт показан компактной формулой, а сверху появляется палитра цветов реагентов.
  • Кнопка ✕ скрывает рецепт сразу в обоих оформлениях. Счётчики скрытых считаются по рецептам.

Изменено

  • Формулы больше не лежат отдельным разделом: каждая стоит в своей категории на месте карточки (К, Б, В, С, М, П, Р).
  • Оформление по умолчанию стандартное. Выбор не сохраняется: после обновления страницы снова открывается стандартное.

Удалено

  • Раздел «Эксперимент · все препараты в формате формул» в конце страницы. Весь его контент сохранён в переключателе.

Исправлено

  • Категория не сворачивалась в экспериментальном оформлении (правило режима перебивало правило сворачивания).
1.22026-11-20Сворачивание и скрытие

Добавлено

  • Категории сворачиваются и разворачиваются кликом по заголовку. С клавиатуры: Tab к заголовку, затем Enter или пробел.
  • Кнопка ✕ на каждом рецепте скрывает его до обновления страницы.
  • В заголовке категории счётчик «скрыто: N · показать»: клик возвращает скрытые рецепты этой категории.
  • Панель над категориями: «Свернуть все», «Развернуть все», «Показать скрытые (N)».
  • Файл script.js с логикой сворачивания и скрытия (без библиотек).
  • Журнал изменений CHANGELOG.md.

Изменено

  • В карточке формулы объём (100u · ×4 = 400u) выровнен вправо перед кнопкой ✕.
1.12026-11-20Салициловая кислота

Добавлено

  • К5 · Салициловая кислота в категории К (последней в очереди). Рецепт: Транексамовая + Фторсерная + Гидроксид натрия + Бикаридин по 25u, нагрев >370K, ×4 = 400u.
  • Формула салициловой кислоты в разделе формул.
  • Цвета реагентов для новых веществ: .r-fsa (Фторсерная), .r-naoh (Гидроксид натрия), .r-bic (Бикаридин).

Изменено

  • Подпись категории К: «Пентеновая → Дексалин+ → Артипластины → Оксандролон → Салициловая».
  • Стили вынесены из index.html в отдельный style.css. Оба файла должны лежать в одной папке.
1.0Исходная версия

Добавлено

  • Категории К (Критически важные), Б (Бой), В (Вирусные заболевания), С (Ситуативные), М (Материалы), П (Примеси и пропорции), Р (Разное).
  • Раздел «Эксперимент» с палитрой реагентов и формулами всех препаратов.
  • Весь код в одном файле.

Известные замечания

  • В формуле «Фалангимин + Пентеновая 1:2» используется CSS-класс .r-fal, которого нет в style.css, поэтому слово «Фалангимин» там не окрашено.
  • Для ×4 нужно по 100u каждого промежуточного компонента, а одна партия даёт 80–100u (в К1, К4 и К5). Последний цикл придётся добирать с запасом.
